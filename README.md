# Petropolis Club Finder

Necesito hacer un formulario de filtro para una campaña publicitaria de Petropolis Club, este debe empezar como la segunda imagen que te adjunte pero añade técnicas de persuasión colocando un valor antes de 449.000, luego de dar clic al botón preguntar por nuestros planes debe aparecer una pregunta que diga "Cual es el nombre de tu peludito" después una pregunta que diga "Cuantos días a la semana esta interesado en dejarnos a tu peludito" con un barra para seleccionar de 1 a 5 y por ultimo la dirección para verificar cobertura de la ruta. después un botón donde los guie a whatsapp al siguiente numero 350 381 8555. la web estéticamente debe tener animaciones fluidas pero sin perder la carga rápida ya que se puede perder un lead caliente por esta razon y debe verse similar a la segunda imagen adjuntada pero con los colores de la primera imagen que es el logo
